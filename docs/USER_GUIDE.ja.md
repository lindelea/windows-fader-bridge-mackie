# Windows Fader Bridge for Mackie Control ユーザーガイド

[简体中文](USER_GUIDE.zh-CN.md) ・ [English](USER_GUIDE.en.md) ・ [ホーム](../README.md)

## このアプリについて

Mackie Control / MCU モードの MIDI コントローラーから Windows オーディオミキサーを操作します。フェーダー、エンコーダー、ボタン、LED、メーター、再生情報を Windows とリアルタイムに同期します。

特定機種専用のドライバーではありません。iCON P1-Nano では実機確認済みです。他の MCU コントローラーも基本プロトコルは共通ですが、追加ボタン、ディスプレイ、ランプの動作は異なる場合があります。

## 動作条件

- 64 ビット版 Windows 11。
- Mackie Control / MCU モードを持つ MIDI コントローラー。
- 機種によってはメーカー指定の USB ドライバー。

EuControl、Avid ソフトウェア、仮想 MIDI ケーブル、開発ツールは不要です。

## インストール

1. [Releases](https://github.com/lindelea/windows-fader-bridge-mackie/releases/latest) から、ファイル名が `Setup-x64.exe` で終わるインストーラーをダウンロードします。
2. 以前に起動したポータブル版を終了し、インストーラーの案内に従います。
3. スタートメニューから **Windows Fader Bridge for Mackie Control** を起動します。

現在は有料の Windows コード署名証明書がないため、「不明な発行元」と表示される場合があります。本リポジトリからのみ入手し、必要に応じて公開されている SHA-256 値を確認してください。

## 初回接続

1. コントローラーを HUI ではなく **Mackie Control / MCU** モードにします。
2. アプリの **デバイス** ページでデバイスを追加または選択します。
3. MIDI 入力と出力を選びます。入力は操作を PC へ、出力はフィードバックをサーフェスへ送ります。
4. 通常は Generic Mackie Control、P1-Nano では専用プロファイルを選びます。
5. タッチ保護を有効のまま保存します。自動接続は既定で有効です。手動モードでは **接続** を押します。

Cubase、他の DAW、本アプリで同じ MIDI ポートを同時に使用しないでください。P1-Nano では Cubase と Windows 操作を別の DAW レイヤーに分け、Windows 用に選んだ専用ポートを使えます。

## 既定の操作

- チャンネルフェーダー：Windows アプリまたはオーディオデバイスの音量。
- Master フェーダー：Windows の既定出力音量。
- エンコーダー 1：現在のチャンネル音量。
- エンコーダー 2：パン／バランス。押すとセンターに戻ります。
- Mute / Solo：実際の状態を操作・表示します。
- Bank / Channel：オンラインチャンネルのページ移動・選択。
- メーター：リアルタイムのオーディオレベル。
- Transport：Windows メディアセッション対応プレーヤーを操作し、曲名、アーティスト、時間を表示します。

終了したアプリは一覧から外れ、新しいアプリは自動的に追加されます。フェーダーに触れている間は対象一覧を並べ替えません。

## ボタンとエンコーダーのカスタマイズ

**ボタン割り当て**、**エンコーダー割り当て**、**Jog と方向**で物理操作子を選び、Windows、メディア、ウィンドウ、オーディオのコマンドを割り当てます。学習中、選択中のデバイスから認識した入力はプレビューだけ行い、コマンドは実行しません。

エンコーダー 3～8 は左回転、右回転、押下を個別に設定できます。通常 Jog、Move、Zoom も独立です。Navi / Focus は機器本来の動作を保持します。

P1-Nano ではデバイスページから Windows 80 キープリセットを利用できます。先に iMAP の設定をバックアップしてください。指定したタッチ位置だけを変更し、他の DAW レイヤーへは書き込みません。他機種はコントロール学習で設定します。

## 設定とショートカット

表示言語、トレイ常駐、Windows サインイン時の起動、グローバル呼び出しショートカットを設定できます。既定は `Ctrl+Alt+Shift+M` で、変更可能です。ウィンドウを閉じると通常は非表示になります。再起動や完全終了はトレイメニューから行います。

各コントローラーは独立したポート、接続方法、割り当てを保存します。最大 16 台の MCU メインユニットを登録できますが、同じ MIDI ポートを複数設定で共有することはできません。

## トラブルシューティング

**MIDI ポートがない：** 電源と Windows での認識を確認し、ポートを使用中の DAW を終了してから再選択します。

**操作できるがモーター／LED が動かない：** 出力ポートを確認し、iMAP・メンテナンス用ポートを選んでいないことを確認します。

**Master または左右選択が動かない：** MCU モードと入出力の組み合わせを確認します。P1-Nano では選択した DAW レイヤーと同じ番号のポートを使います。

**アンインストール：** Windows 設定 → アプリ → インストールされているアプリから削除します。再インストール用にデバイス割り当ては保持されます。
